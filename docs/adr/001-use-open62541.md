# ADR-001: Use open62541 for OPC UA connectivity

## Status
Accepted

## Context

The gateway requires an OPC UA client suitable for Linux and future embedded/edge deployments.

The portfolio project should not depend on a proprietary industrial SDK.

## Decision

Use `open62541` as the OPC UA implementation.

Encapsulate its C API behind a C++ adapter.

## Alternatives considered

- Unified Automation C++ SDK
- Softing OPC UA SDK
- Prosys SDK
- vendor-specific OPC UA SDKs

## Consequences

### Positive
- open source
- portable
- established OPC UA implementation
- suitable for Linux/embedded environments
- no proprietary runtime dependency

### Negative
- C API requires careful C++ ownership wrapper
- library-specific status codes require mapping
- certificate/security configuration will require additional work later
